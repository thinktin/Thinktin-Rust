thinktin G1.0 / 圆弧几何规范版
日期：2026-10-30

本包将已确认的彩色双圈罐子 Logo 规范为 96 段圆弧与 2 段直线。
用途：设计交接、放大缩小、印刷及按参数独立复建。

重要精度边界
1. 本包的“1:1”指精确复建本矢量规范版，不是逐像素复制原生成位图。
2. 轮廓经过圆弧拟合、对称与线宽规范化；渐变另有固定定义。
3. 圆规/直尺可以按坐标、半径与端点定位来复建；这是工程制图式标注，
   并非声称原位图具有某种未给定的黄金比例或无刻度尺规构造证明。
4. SVG 和 JSON 是数字复建依据。PDF 为设计说明与尺寸表，页面上的图形
   为排版缩放后的示意，不要直接量页面上的图形长度。

坐标与画板
- 画板 1000 x 1000 U，原点在左上，x 向右、y 向下。
- 输出画板边长为 L 时，1 U = L / 1000。
- SVG 设为 100 mm 正方形，因此此尺寸下 1 U = 0.1 mm。
- 不对 X、Y 方向分别拉伸；两方向必须使用相同比例。
- 无文字；白色背景 #FFFFFF；罐子线条 #000000。
- 路径顺序为 B -> R -> I -> S。
- B 罐体线宽 22 U；R 外罐口 21 U；I 内罐口 16.5 U；S 双圈 22 U。
- 所有开口端点使用圆头，线段连接使用圆连接。

圆弧复建
- 每一记录给出 P0 起点、P1 终点、C 圆心、R 半径、a0 起始角和 da 扫角。
- JSON 中角度为弧度；CSV / PDF 中角度为度。
- x = Cx + R*cos(a0 + t*da)
  y = Cy + R*sin(a0 + t*da), 0 <= t <= 1。
- y 向下，因此 da > 0 是顺时针 CW，da < 0 是逆时针 CCW。
- 直线记录只需要 P0、P1。
- 依记录顺序连接；R 路径闭合，B / I / S 为开放路径。
- 基础椭圆参数只记录建模种子。实际轮廓以圆弧记录为准，
  不要用一个新的椭圆代替它，也不要把 SVG 圆弧改成重新拟合的曲线。
- 数字复建应读取完整 JSON / SVG；PDF 三位小数供手工定位与核对。

描边边界与圆规线
- 圆弧表描述笔画中心线；描边宽度为 w 时，可用同心的 R-w/2、R+w/2
  两条圆弧取得边界（再取笔画轮廓并集）。直线取两条平行偏移线。
- 开放路径的圆头以端点为圆心、w/2 为半径。
- 双圈交叉处取轮廓并集，不增加上浮、阴影或遮挡效果。
- 辅助圆全部来自实际圆弧；有些大圆的圆心在图面之外，完整坐标见表。

渐变复建
- 单个全局线性渐变：gradientUnits=userSpaceOnUse，color-interpolation=sRGB。
- 渐变轴起点 (324,510)，终点 (670,605)。
- 色标：0% #0754FF；18% #0089FF；32% #00C9E9；45% #3268FF；
  56% #6A24FF；70% #B32CF4；82% #EB35CF；94% #FF4C80；100% #FF6B3B。
- 渐变作用于整个 S 路径，按画板坐标插值，不是按路径长度逐段换色。
- 交叉处因此具有一致颜色。渐变轴外按端点色延展。

自动复建
在解压目录打开终端：
    python3 rebuild.py
或指定输入及输出目录：
    python3 rebuild.py thinktin-geometry.json rebuilt
脚本不需要原始图片、字体、绘图库或联网。
它生成彩色/黑白 SVG、辅助线 SVG、CSV 和几何校验结果。

已完成验证
- 98 段路径无接点缝隙。
- 圆弧端点到其圆的最大数值误差小于 0.000001 U。
- 相邻段切线方向最大偏差小于 0.00001 度。
- 以本参数独立复建的 SVG / CSV 与发布文件逐字节一致。
- 在 1254 x 1254 像素下，与已确认原图的双向轮廓边界距离：
  平均 0.878 px；95 分位 2.236 px；最大 5.000 px。
  测量阈值为 min(R,G,B)<180，包含抗锯齿与线宽规范化影响。
- 不同软件的抗锯齿、色彩管理与显示缩放可能导致屏幕像素不同，
  不改变 SVG 的数学路径和规定尺寸。
