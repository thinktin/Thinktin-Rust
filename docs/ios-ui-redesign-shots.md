# iOS 改版截图对照表

`tools/apple/screenshots.sh` 出的每张截图该和哪几张参考截图比、对的是 [改版规范](ios-ui-redesign.md) 哪一节。还原度评审照这张表逐张看。

- 怎么出图：GitHub 上推到 `ios-screenshots` 分支（`git push -f origin HEAD:ios-screenshots`）或手动跑 iOS screenshots，
  产物 `ios-screenshots`；Codemagic 推到 `codemagic/ios-screenshots`。旧系统的回退见规范 7.6 第 3 条。
- 文件名 `NN-名字-light.png` / `-dark.png`。“外观”一列：浅深是浅色、深色各一张，浅是只有浅色（一共 70 张）。编号定了不改，新页面往后加。
- 参考截图（120 张，2026-11-01）不在仓库里，编号就是文件名开头的数字（`01-Bot列表.jpg` 是 1）。“无”是参考里没有的 ThinkTin 页面，
  看它和改版的页面是不是一套样子（规范第 2 节）。
- 怎么打开见脚本里的清单（`THINKTIN_OPEN_SCREEN` 的值、深链）；Botin 的页面都是演示数据首页第一个 Botin “写作助手”的。

## 截不到的参考

脚本只能启动 App、按启动变量打开页面，要真的点、滑、长按的状态截不到（以后可以写 XCUITest 去点），要在模拟器或真机上看：

- 系统菜单：对话“…”（3）、附件（8）、资料页“…”（10）、语音和语言的选项（13–17、85–88）、首页长按（32、33、112）、保险箱“+”（58）、
  反馈的 Botin（77）；左滑（110）；消息长按和表情（6、90）；改名弹窗（68）。
- 要输入或要别的数据：查找没结果（5）、搜索有字（79、80）、引用回复（7）、新 Botin 的欢迎卡（118）、图片全屏（24、25，演示数据没有图片
  产出物）、表单追加的字段（94–99）、修改规则和另一组的新规则（64、100）、取消隐藏后的空状态（116）。
- 页面里的其他分页和 sheet：头像的生成、上传（19、20）、观看页的控制模式和菜单（30、31、89）、使用说明（28）、隐藏说明（115）、
  连接的其他分类（40–51）、推荐和精选的完整列表（101–104）、别的插件详情（39、105–107）。
- 不做或还没做：链接分页（26、84，换成“文件”）、分组（91–93）、登录方式（108，用户自己设计）、冷启动的启动屏（109）、电脑启动页（27）。
